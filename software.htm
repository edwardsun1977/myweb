軟件Software UI & Help Files

Preparing software for release has never been easy. Every dialogue, every menu string and every page of on-screen help must be translated — and then resized, because Chinese text rarely occupies the space English did.

Where special regulatory requirements apply to software products, it is not enough to translate the interface: certain applications must be modified in substance to remain compliant with local law and regulation. We plan for that from the first build.

We maintain the tools and recruit the specialists needed to localize software both linguistically and culturally. The result translates directly into higher revenue and larger market share for our clients, and — combined with our localization methodology — supports a flawless, cost-effective, simultaneous release.

What the Work Involves

  • String extraction — resources pulled from binaries, scripts and resource files, with placeholders and accelerators kept intact.
  • Translation and resize — Chinese strings shortened or reflowed so that dialogues, buttons and toolbars still fit after localization.
  • Context review — screenshots and running builds checked in sequence, so that no message is translated out of context.
  • Consistency control — a shared glossary and translation memory across the interface, the help system and the printed documentation.
  • Build verification — the localized build tested on the target platform before hand-over.

Because the interface, the help and the manual are usually produced by different teams in the source language, we align them in Chinese: one product, one vocabulary, one voice.
